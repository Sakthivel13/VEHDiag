Features

Professional diagnostics, modular by design

Every capability sits on the same open diagnostic engine: transport, protocol, vehicle and application layers — extensible, testable, independent.

DTC diagnostics

Read stored, pending and permanent codes (OBD 0x03/0x07/0x0A, UDS 0x19). Every code is decoded into system, description, severity and status — with freeze-frame context and clear-code support (0x04 / 0x14).

P0130 · B1 · U · C · status bits

Live data

OBD Mode 01 PID decoding with correct scaling (A, B, C, D formulas), multi-PID batching, and configurable signal dashboards streamed over WebSocket. EV signals include SOC, SOH, cell voltages, DC bus voltage/current and motor temperatures.

RPM · ECT · MAP · STFT · SOC

VIN + vehicle identification

Read the VIN (OBD 0x09-02, UDS 0x22 F190) and decode WMI, model year, plant and check digit. Save vehicles with engine, fuel type, transmission and mileage; identify-by-VIN on every new session.

17-char VIN decode

Freeze frame

OBD Mode 02 captures the engine snapshot stored when a fault triggered: RPM, load, coolant temp, speed, fuel status and the fault code — shown side-by-side with the DTC.

OBD 0x02

ECU information

Per-module calibration IDs, VIN, ECU name, hardware/software versions (OBD 0x09). UDS ReadDataByIdentifier (0x22) for OEM identifiers, part numbers and software IDs.

OBD 0x09 · UDS 0x22

OBD terminal

Raw ELM327 AT and OBD-II command line with log-style scrollback — exactly what advanced technicians expect. The same terminal powers the built-in simulator so scripts run without hardware.

ATZ · 0100 · 03 · 09 02

Reports & history

Every session is stored with a unique ID. Export branded PDF (print-to-PDF), JSON and CSV: vehicle, VIN, technician, device, ECUs scanned, DTCs, live-data summary, status and recommendations.

PDF · JSON · CSV

EV architecture

Pluggable ECU definitions — ECU ID, CAN IDs, protocol, DIDs, DTCs, signals, routines — for BMS, VCU, MCU, OBC, DC-DC, charger, inverter and telematics. See EV diagnostics.

BMS · VCU · MCU · OBC

Failure handling

Timeouts, no-response, malformed frames, NRC 0x78 response-pending, bus-off, disconnects — every failure path is modeled, logged with the session ID, and can never corrupt the next session. Each session owns its state.

session isolation

Admin dashboard

Users, organizations, vehicles, sessions, devices, DTC/ECU databases, subscriptions, audit logs and analytics — role-gated for TECHNICIAN, WORKSHOP_ADMIN, ADMIN and SUPER_ADMIN.
