How the APK is distributed (the "indiag.zip pattern")

1

Build

The APK is built by the project's own pipeline (scripts/apkbuild) from source in apps/mobile — independent code, independent release key.

2

Commit

The signed APK and its .zip mirror are committed to the GitHub repository, exactly like the reference product ships indiag.zip.

3

Serve

This website serves them at /downloads/VEHDiag.apk and /downloads/VEHDiag.zip, with version, size, SHA-256 and a QR code — plus a Play Store link as the secondary channel.

Verify your download

# On Linux / macOS / Android (Termux)
sha256sum VEHDiag.apk        # compare with SHA256SUMS.txt
unzip -l VEHDiag.zip         # should contain base.apk

# The APK signature can be verified with apksigner (Android SDK):
apksigner verify --print-certs VEHDiag.apk
