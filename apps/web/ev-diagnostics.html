EV architecture

Electric powertrains, fully decoded

VEHDiag treats every EV module as a pluggable ECU definition — CAN IDs, diagnostic protocol, DIDs, DTCs, signals and routines. New models are profiles, not code changes.

BMS

Battery management: SOC, SOH, cell voltages, temperatures, charge/discharge limits, balancing status, isolation.

VCU

Vehicle control unit: torque arbitration, drive modes, safety states, power limits, system faults.

MCU

Motor controller: motor speed, torque, phase currents, IGBT/inverter temperature, derating, faults.

OBC

On-board charger: AC input, charge power, HV output, temperature, CP/PP pilot states, session DTCs.

DC-DC

HV→12V converter: output voltage/current, efficiency, temperature, load shedding faults.

Charger

DC fast-charge handshake, requested/actual current, connector temperature, insulation monitor.

Inverter

DC bus voltage/current, motor torque/speed, switching temperature, over-current events.

Telematics

TCU health, modem state, GNSS, CAN gateway diagnostics, OTA update status.
